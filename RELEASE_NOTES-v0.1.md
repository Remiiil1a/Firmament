**Firmament - v0.1 (edit of coderbot's Steadfast)**

Download the zip from **Assets** below - not the "Source code" archives, which
are generated by GitHub and are not the built shader pack.

An edit of Steadfast 0.8.0 by Remiiil1a, adding:

* **labPBR 1.3 material support** - normal, specular/metal, material ambient
  occlusion, subsurface scattering, porosity/wetness and emissive maps, with a
  per-channel debug view.
* **Reflections** - a sky reflection term per material, plus screen-space
  reflections of the world, and specular reflections on stained glass and panes.
* **The End** - its own light, a void glow, End haze, and a debug view for the
  dimension checks.
* **A tangent frame fix** - material tangents now come from the geometry's own
  tangents, which fixes normal maps flipping at distance.

The defaults are the configuration this version was tuned with, so it looks as
intended out of the box. The `✎ EDIT默认 style` profile restores that
configuration after trying one of Steadfast's own styles.

**Requirements:** Iris 1.5 or newer, Minecraft 1.18.2 or newer. OptiFine is not
supported - that is Steadfast's limitation, not this edit's.

**Known rough edges in this version:**

* TAA is **off and unfinished**. Its options do nothing until it is switched on.
* Parallax occlusion mapping is **off and unfinished**.
* Reflections only see what is on screen, only from the previous frame, and a
  rough surface gets a single sample rather than a blur.
* Reflections can appear where sky light reaches the ground but the sky is not
  visible (under overhangs, through glass).
* Entity materials are an experiment; the tooltip explains how to check.
* No testing across GPU vendors - this was verified in game by one person.

**Performance:** this costs noticeably more than upstream Steadfast. Every lit
surface writes two extra buffers for the material data (about 12 bytes per pixel
of extra bandwidth), and screen-space reflections march the depth buffer on
every pixel that passes the roughness limit. If you need the frames back: turn
off screen-space reflections, then sky reflections, then lower the step count or
tighten the roughness limit, then drop a quality profile. The README has the
full list.
